ai-chat-assistant-widget

This page embeds the widget with a plain <script> tag and zero build step — the way a static site with no bundler would use it. The bubble should appear on the right edge of the viewport, vertically centered.

By default this points at a local wrangler dev worker at http://localhost:8787. Start it from packages/worker before sending a message, or remove the worker-url attribute below to see the "not configured" empty state.
